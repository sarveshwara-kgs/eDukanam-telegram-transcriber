eDukanam Telegram Transcription

Voice-to-text bot powered by Groq Whisper API

About

This Spring Boot service receives Telegram webhook updates for voice messages, downloads audio files, and sends them to the Groq API for transcription.

Endpoints

  • POST /telegram/webhook — Telegram bot webhook
  • GET /health — Service health check
POST /telegram/webhook

Technology

  • Spring Boot 3.3.4
  • Java 17
  • Maven
  • Groq Whisper (via WebClient)
